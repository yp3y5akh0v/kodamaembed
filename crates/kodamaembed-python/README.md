# kodamaembed-python

The native module of the `kodamaembed` Python package, built with
[maturin](https://www.maturin.rs/) from the repository's `pyproject.toml`.
The public Python API lives in [`python/kodamaembed`](../../python/kodamaembed),
and the [Python guide](../../docs/python.md) documents it.

```text
maturin build --release
```
